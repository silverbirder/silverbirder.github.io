やよい軒でカツ丼を間違えて2つ頼んでしまいました。  
カツ丼がテーブルに届くまで気づかず、2つ目のカツ丼をテイクアウトに変更してもらいました、すみませんと感謝です。  

## UI が悪い！

かもしれないが、間違いを気づけたタイミングがたくさんあったし、私の不注意なので UI は悪くないです。  

- 支払い時に、2つのカツ丼の値段になっていた
  - コード決済で金額を見なかった
- 出力された食券が、2枚あった
  - 見ずにそのままテーブルに運んだ

## 店員さん、ありがとう

テーブルに私一人しかいないのにカツ丼2つも注文している私を店員さんが見ていて、  
店員さんが「お友達がくるのかなって」と私に話しかけてくれました。  
オードリーの漫才かの如く、私と店員さんで大笑いしてました。  

カツ丼2つとお味噌汁2つを運んできてくださったのですが、  
カツ丼1つをテイクアウト用の器に移して頂き、お味噌汁はそのまま頂きました。  
お値段の変更はありませんでした、、、。  
お手数おかけしました。  

## ぼーっとしてた

やよい軒に行く前に2時間ぐらい、温泉に入ってました。  
サウナ、壺湯、寝湯と堪能して、もう最高にトトノっていました。  
まあそんな状態でやよい軒の食券機の前に立ったので、間違えてカツ丼を2回タップしちゃったのでしょう。  
は〜、やっちゃった〜。  

よく「そんな UX になる UI が悪いんだ！」と強い口調で話す人もいるのでしょうが、  
今回のケースにおいては完全に私のミスです。  

## 終わりに

テイクアウトしたカツ丼、妻と半分こして頂きました。  
とても美味しかったです、今度は間違えずに注文します。
