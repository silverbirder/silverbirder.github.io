OpenAI の Codex を普段から愛用しています。  
開発において、VS Code や IntelliJ IDEA という枯れたメジャーエディタを使っていましたが、  
最近は Codex Desktop App だけでも案外イケるかも？と感じています。  
気に入っているところを書こうと思います。  

## UI

Codex Desktop App の UI がなんとなく気に入っています。  
**インタラクションフィードバックが自然に感じ** て好きです。  
これが一番良い！というものではなく、全体的にフィードバックが好きです。  

ホバーしたら欲しいと思ったピン留めが出てくれたり、  
情報量が段階的に表示されるようになっているし、  
左パネルや右パネル、下パネルの開閉アニメーションが滑らかだし、  
尖ったデザインじゃなくて汎用的なデザインなので理解しやすいし。  
配色や余白も余裕がある圧迫感のない感じがあって良いです。  

全体的に私の期待するフィードバックと一致するので **手に馴染みます**。  

## 開発

チャットに加えて、ターミナルや、ファイル、ブラウザ、レビュー があります。  
**純正で、特に設定することは何もありません**。  

ターミナルで動かしていると、そのログを添付しなくても読み取ってくれるため、  
**わざわざ貼り付ける必要がありません** 。  

ファイルだと Git リポジトリのファイルをフォルダツリーで表示されますし、  
ファイルを開くとファイルを直接編集できるし、コードに対してチャットをすることができます。  

ブラウザだと、アプリを起動させて表示させると、  
**表示されている画面にクリックしてコメントを送ることができます。**  
加えて、UI がおかしいか場合に、Codex 側がブラウザを読み取ってくれるので、  
わざわざ スクリーンショットなどを送る必要もありません。  

レビューは、よくあるソースコードの変更箇所を GitHub などと同じように差分がみれます。  
ファイルを1つずつ確認済みでチェックできるので、私の普段「チェックしたものをステージに上げる」という体験と似ています。  
コミットメッセージも、自動的にメッセージを書いてくれます。  
まあ、このあたりは驚くところはあまりないです。  

開発エディタとチャットアプリを交互に行き来するよりも、  
1つのアプリ内（Codex Desktop App）で完結している方が より直線的に作業ができてよかったです。  

まあそれでもやっぱり **気になる箇所は 大小かかわらずあります**。  
けれどそれを差し引いても、1つのアプリ内で完結する開発体験は、悪くないんじゃないかなと思い始めています。  

## チャット感

チャットしている感があって好きです。  
Codex に言葉を投げかけると、"ひっそりと仕事を淡々と進めて終わってから返事を返す" のではなく、  
"返事を返した後、これからしようとしていることを独り言のようにチャットで書いて、作業に入る" ため、  
任せて良いかどうか 少し見守る余裕ができます。  

途中で間違った方向でガリガリ走る前に、差し込んで止めることができますし、  
もちろん他のアプリでも同じことができると思うのですが、  
UI のインタラクションフィードバックが適度で私の作業スタイル（？）に合っている気がします。（笑）  

## その他

作業が終わったら通知してくれるし、  
作業中のチャットはピン留めして終わったら外したりしています。  
スマホから作業ができるし、クラウド環境もあるし、並列作業もできます。  

たぶんどこも似たような機能は大体揃っていて（知らんけど）、  
私が気に入るのは 操作体験 が自然に溶け込みやすいやつなのかなと思います。  

## 終わりに

私のポリシーの1つに「大手・メジャーなもの」や「標準・純正」、「枯れたもの」などを使いがちです。  
Codex Desktop App だけでできるなら、私はそれで十分満足です。  
今日も明日も、お世話になります。
