Mac で作業中に『ディスク容量がいっぱいです』という通知が飛んできました。  
え？と思い見てみると **"使用済み: 440GB / 全体: 489GB"** と空き容量 49GB になっていました。  
そんなバカな！？と驚き、諸々整えていくと **約275GB** 削除しました。  
やったことについて、まとめておきました。  

## 内訳

消した容量は、以下の内訳の通りです。

- パッケージ管理
  - ~/.npm: 72GB
  - ~/.asdf: 7GB
  - mise 古いランタイム: 2GB
  - pnpm 未使用パッケージ: 5GB
- キャッシュ
  - Docker cache: 18GB
  - ~/Library/Caches: 21GB
  - VSCode cache/history: 4GB
- モバイルアプリ
  - iOSシミュレータ(CoreSimulator): 29GB
  - Android SDK / NDK: 7GB
- GitHubリポジトリ: 65GB
- ドットフォルダ: 45GB

72GB って...どんだけ使ってんねん...！  
みなさん、定期的にお掃除ましょうね。  

## 少し詳しく

基本的にキャッシュデータが一番大きいです。  
npm や Docker、Library（Macのアプリたち）がドンドンと溜まって行ったのです。  
Library においては、既にアンインストールしたアプリのデータも残っていました。  
ドットフォルダももう入れていないアプリの残骸とかが溜まっていました。  

次に大きかったのは、シミュレータ系です。  
iOS や Android のシミュレータで未使用なものが溜まっていました。  
なんなら、XCode をアンインストールしていたのに iOSのシミュレータは直接消せない（保護されている）ため、  
XCodeを入れてシミュレータ消してXCode消して、なんてこともしました。  

あとはGitHubリポジトリですが、これらはケースバイケースでした。  
永遠と蓄積されていたignore系ファイルが溜まっていたので、消したというのがメインです。  

## 終わりに

定期的にストレージを見直しましょうね。
