AI ぽい UI デザインを脱したい人向けの本を執筆しました！  
文字・余白・形・色・操作 など合計8つの観点で、UI デザインを考える本になります。  
ぜひお手に取って、みてもらえればと思います。  
対象読者は、 UI デザインを考える人、作る人向けの本になります。  

https://zenn.dev/silverbirder/books/ui-craft-techniques

## 執筆の動機

AI っぽい Web サイトを多く見かける機会が増えました。  
それが悪いという訳ではないのですが、量産型な Web サイトというのは記憶に残らないと考えています。  
じゃあ記憶の残る Web サイトってなんだろう？というのが出発点です。  
自問自答を繰り返した結果、私の中で **『細部に拘るUI』** と思うようになりました。  

- ボタンをクリックしたら、ちょっとした遊び心あるフィードバック
- コンテンツが整理整頓されていて、疲れない余白設計
- 背景色が鮮やかな色で、楽しげなトーンなコピーや配色

当初は『細部を見るUI観察』のようなテーマで考えていたのですが、  
執筆を続けるうちに書くコンテンツにカテゴライズできそうな視点を見つけました。  
それが、本書の『個性を磨くUI観点』です。  
文字・余白・形・色・操作などを合計8つの切り口で UI を見ることで、  
どういうポイントでデザインを考えたら良いのかという思考のサポートになればと思っています。  

## ちょっと紹介すると

形・あしらい・トンマナについて、以下のページで無料公開しています。  

https://zenn.dev/silverbirder/books/ui-craft-techniques/viewer/05-shape-decoration-tone

Web サイトには、いろいろな形が使われています。  
ボタン1つ取っても、いろいろなデザインのパターンがあります。  

- 角は丸くするか
- 長方形、正方形、丸型、特殊か
- 境界線をつけるか
- アイコンを添えるか
- 縁をつけるか
- ...etc

これは服のボタンのデザインをどうするか のような小さなことかもしれません。  
機能としてはクリックできればなんでも良いですが、**装飾するパターンは無限大** です。  
そんな細部において、Web サイトの世界観・コンセプトに沿った根拠あるデザインになっているかを考えることで、  
Web サイト全体の個性が滲み出ると思います。  

## 他には

Web サイトで書かれている文章の書きっぷりによっても印象は変わりますし、  
フォント1つ違うだけでも変わります。  
配色をどうするか、余白や線をどうするか、奥行きをどうするか、操作の動きをどうするか、たくさんあります。  
1つ1つを丁寧に拘るからこそ、**愛着が沸くし差別化** にもつながります。  
多くの人はそんな細部に気づくことなく、ただ「なんか良い」と思うことがありますが、  
むしろそれが、良い UI デザインではないのかなと 最近はそう思うことがあります。  

## 終わりに

過去の経験を集めた本になりまして、執筆のおかげで知識がより昇華した感覚があります。  
もしよろしければ、読んでみてください。
