今まで読んだ UI 関連の書籍や実務経験を踏まえて、  
私も本を書いてみようかなと思いました。  
完成するか不明です。  

## 元コンテンツ

執筆にあたり、本の内容は私の中である程度ストーリーがありました。  
ただゼロから書くよりも、私には今まで書いたブログ記事があります。  
「これらの情報を元に本にするとしたら、どういう記事になりそう？」Codex に感想を聞きました。  
1読者として、どういう印象を Codex に与えれるのか知りたいのです。  

そうすると UI を構成するさまざまな要素が「なぜ、そうしてる？」という疑問を深ぼっている、  
**"UI を観察する"** というテーマが良さそうという感想をもらいました。  
「お、わかってるじゃん」と少し嬉しかったのです。  
私自身気づいていなかったのですが「なぜ、そのUIなのか？」と深掘り考えることで、  
細部まで拘り使いやすい UI を練りたいのです。  

## どこに出すか

Zenn に出そうと思います。  
特に出版社とのコネクションはないので、出せるところに出そうかなと。  
昔技術書典で書いた本は、最終的に Amazon に出しているので Amazon にも出してもよいかもですね。  
Amazon に出しているのは "はじめてのWeb Components入門: 4つの基本機能から関連ライブラリまで" という Web Component に関する入門書です。  

- [はじめてのWeb Components入門: 4つの基本機能から関連ライブラリまで - amazon.co.jp](https://www.amazon.co.jp/gp/product/B08CY2QCFV/)
